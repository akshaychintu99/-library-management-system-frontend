# AC Library Services — Frontend

React + Vite + CSS frontend.

## GitHub
Create a separate GitHub repository:
`https://github.com/YOUR_GITHUB_USERNAME/ac-library-services-frontend`

## Local
```
npm install
npm run dev
```

Set `.env`:
```
VITE_API_URL=http://localhost:8080/api
```

## Deploy
### Vercel
Build: `npm run build` · Output: `dist`

### Netlify
Build: `npm run build` · Publish: `dist`
